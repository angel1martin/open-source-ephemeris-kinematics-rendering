# Open-Source Ephemeris and Spatial Kinematics Rendering (OS-ESKR)

Este repositorio alberga el núcleo de desarrollo de un motor web interactivo de código abierto diseñado para acoplar la cinemática galáctica contemporánea con los sistemas de información y registros astronómicos históricos mesoamericanos.

## 🛠️ Arquitectura Tecnológica
* **Motor de Renderizado:** Desarrollado sobre WebGL y WebGPU para simulación interactiva 3D nativa en navegadores web estándar sin complementos privativos.
* **Cálculo de Efemérides:** Implementación de librerías astronómicas de alta precisión compiladas mediante WebAssembly (Wasm) para retrocálculos en tiempo real del orto helíaco de Venus y tránsitos solares.
* **Pipeline de Datos Históricos:** Estructuración de datos cartográficos y genealógicos procedentes de crónicas novohispanas (1598-1615) utilizando formatos abiertos interoperables JSON y GeoJSON.

## 🔬 Sustento Científico y Ciencia Abierta
El marco teórico, los isomorfismos astronómicos, las matrices de escala y los modelos óptico-especulares que rigen los algoritmos de este software se encuentran completamente documentados, protegidos y registrados bajo los principios de la ciencia abierta.
